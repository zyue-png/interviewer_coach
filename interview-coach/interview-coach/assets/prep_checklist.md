# 面试前 24 小时检查清单

## 内容与证据

- [ ] 准备 2–3 个与目标岗位最相关的项目故事。
- [ ] 每个故事都能说清 Situation、Task、Action、Result。
- [ ] 写下关键指标的基线、时间范围、口径和个人贡献。
- [ ] 为简历中每个高频关键词准备一个真实例子。
- [ ] 准备一个失败案例、一个冲突案例和一个取舍案例。
- [ ] 检查简历中的时间、职位、技术栈和数据是否前后一致。

## 岗位与表达

- [ ] 用一句话说明为什么匹配这个岗位。
- [ ] 准备 60 秒自我介绍，围绕岗位需求而不是逐条念简历。
- [ ] 准备 3 个针对团队、业务目标和成功标准的反问。
- [ ] 对不熟悉的技能准备诚实、积极、可验证的补足计划。

## 设备与状态

- [ ] 确认面试链接、时区、联系人和面试形式。
- [ ] 测试摄像头、麦克风、耳机、网络和屏幕共享。
- [ ] 准备简历、项目材料和纸笔；不在面试中展示机密资料。
- [ ] 提前 10 分钟进入，关闭无关通知，保证安静环境。
